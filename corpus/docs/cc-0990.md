# CC-0990: Assign owner for payments-api

- Change type: Ownership assignment
- Requested by: Aria
- Approved by: Nora (Payments lead)
- Effective: 2026-10-12T12:00:00Z
- Risk: Low
- Related project: Project Nova

## Change

Ownership of payments-api is assigned to Aria Okafor, effective 2026-10-12T12:00:00Z.

## Background

The payments API has not had a named owner in the catalog since the Q3 reorg, which left the on-call escalation path
for tokenization and charge failures pointing at a team alias. With the ADR-011 tokenization work landing this month,
the payments team agreed to name a single accountable engineer.

## Rollout

1. Update the catalog entry and the PagerDuty escalation policy for the payments API.
2. Announce in #payments.
3. No code or infrastructure changes.

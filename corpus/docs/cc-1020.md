# CC-1020: Assign owner for infra-k8s

- Change type: Ownership assignment
- Requested by: Gus
- Approved by: Fay (Platform lead)
- Effective: 2026-10-08T10:00:00Z
- Risk: Medium (affects the escalation path for every workload on the cluster)
- Related project: Project Borealis

## Change

Gus Delgado owns infra-k8s, the shared Kubernetes platform, effective 2026-10-08T10:00:00Z.

## Background

Cluster upgrades, node pool changes and the Terraform modules for the platform have been handled by whoever was on
call that week. After the CA rotation scare in INFRA-25, the platform team agreed that one person should hold the
upgrade calendar and approve changes to the cluster modules.

## Rollout

1. Update the catalog and escalation policy.
2. Cluster changes move to the Tuesday platform change window.
3. Terraform changes to the cluster modules require review from the platform team.

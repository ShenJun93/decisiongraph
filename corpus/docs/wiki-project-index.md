# Project index (codenames)

New people keep asking what the star names mean. Each codename is a long-running project; this table lists which
services each one touches. It does not say who owns anything; see the service directory and change control for that.

| Project | Services | What it is about |
|---|---|---|
| Project Orion | billing-gateway | Billing gateway rewrite: invoices, renewals, dunning |
| Project Vega | ml-pipeline, feature-store | Fraud model training and online features |
| Project Nova | payments-api | Payments API hardening and card tokenization |
| Project Lyra | search-index | Search index rebuild and relevance tuning |
| Project Atlas | checkout-web, payments-api, ledger-service | Checkout redesign end to end |
| Project Helix | ledger-service | Ledger correctness and reconciliation |
| Project Comet | notification-service | Notification fan-out and delivery tracking |
| Project Quasar | identity-service | SSO, session hardening and passkeys |
| Project Pulsar | event-bus | Kafka cluster upgrades and schema governance |
| Project Zephyr | analytics-warehouse, feature-store | Warehouse modernisation and offline features |
| Project Aurora | mobile-app, notification-service | Mobile app 5.x and push notifications |
| Project Borealis | infra-k8s | Kubernetes platform, Terraform modules, cluster upgrades |

Topics that come up across projects: Kafka, Postgres, PCI compliance, Terraform, Kubernetes and fraud models.
